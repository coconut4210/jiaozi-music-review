# 饺子专辑短评

听完一张专、心里已经有分，需要一篇能直接发的中文短评时，用这个 skill。


---

## 这个产品解决什么问题

写短评时最费力的，是口气和结构：既要像自己平时发的，又要一篇只说一件事，还不能写成曲目导览或歌手百科。

这个 skill 固定做以下三件事：

1. **听法**：乐评让判断先行。从音乐类型、编曲制作、概念与写作入手，保证内容的多元。2. **力度**：由你给的 10 分制分数决定这篇有多夸、有多狠。
3. **主线**：先和你把核心要体现的内容想清楚，再写正文。

## 当前 skill 在什么场景下触发

Agent 会看 `SKILL.md` 开头的 `description`，对上了就自动调用；你也可以自己用 `/jiaozi-album-review` 点名。

**会触发：**

- 你要写能直接发的专辑短评：说「写乐评」「专辑乐评」「新专乐评」「专辑简评」「短评」「按饺子的框架写」
- 同一条消息里带了歌手 + 专辑名（有分数更好）
- 你明确要饺子判断 × UPEE 书面，或说「融合」「UPEE书面」
- 你在对话里手动附上了这个 skill

**不会用这个 skill：**

- 六种风格菜单那种通用乐评
- 产业长文、逐首歌解说、入坑导购
- 没说要写评，只是闲聊某张专

没给分数、没定主线时，skill 仍会启动，但先问这两项，不直接交正文。

## 你需要提供什么

### 必填（歌手、专辑、分数缺了先问；主线没定则不写正文）

| 输入 | 作用 |
| --- | --- |
| 歌手 | 定位作品 |
| 专辑名 | 定位作品 |
| 10 分制分数 | 决定口气档位。可写 `8`、`6.5`、`8.6`、`8/10` |
| 主线 | 这篇乐评的关键要点。可以自己写，也可以等列出候选再挑 |


主线没定不会写正文。已经写出一句判断时，会先把那句抛回给你确认。

### 选填（写了会用来收主线）

- 你自己的听感
- 专辑中个人喜欢或讨厌的曲目
- 和同音乐人上一张 / 某张对标专的比较
- 年份（有助于检索；没有也可以查）
……

没写听感也可以先开口，但至少需要保留一条乐评主线。你的听感和网上说法不一致时，优先听你的。

## 分数怎么决定你读到的口气

8 分算优秀专（含 8 分）。边界四舍五入。

| 你给的分 | 成品口气 |
| --- | --- |
| 8 分及以上 | 高评：夸奖为主 |
| 7 分到 8 分以下 | 有褒有贬，两边各打五十大板 |
| 6 分到 7 分以下 | 混合：优缺点写清楚 |
| 5 分到 6 分以下 | 以批评为主 |
| 5 分以下 | 苛评：具体且直白、狠 |

---

## 你会拿到什么

第一轮（主线未定）：2～3 句候选，或把你已有的判断抛回确认。

主线点头之后：

- 一篇中文第一人称短评
- 大约 500–800 字（偏上沿，而不是三五行的简单表态）
- 开篇就能看出站哪边
- 全文的核心主线
- 可以直接复制去发


---

## 怎样算一篇合格的成品

自己读一遍，用这几条验收：

1. **三秒内知道站哪边。** 开篇就是核心判断。
2. **整篇只在证明一件事。** 把各段第一句连起来读，应该还是同一条线，而不是「编曲一段、演唱一段、歌词一段」，也不是「类型、制作、概念」三栏填空。
3. **理由能指回声音。** 出现的曲名是为了支撑要表述的制作、听感等元素；而不是报菜名。
4.  **只谈音乐。** 判断落在词曲编唱、概念、整专听感上。
5. **像听完整专的人在说话。** 主语是这张专辑，不是十首单曲拼盘。

不满意时，直接改输入再跑：改分数、补一句你的听感、或指出「主线应该是某某」——比空泛说「再文学一点」有效。

---

## 使用建议

- **先定分，再开口。** 分没定就写，成品力度会对不准。
- **主线比零碎听感重要。** 「情歌唱厚了，满而不散」比列五首喜欢的歌更有用。
- **一张专一次只交一篇。** 要换角度，改主线后重写。
- **当短评用。** 这是发笔记的体量，不是工业长文、不是逐首歌解说、不是入坑导购。
